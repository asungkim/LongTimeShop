 # 중고 거래 플랫폼 팀 프로젝트

중고 거래 플랫폼 개발 및 배포를 목표로 5명의 팀원과 약 3주간 진행한 프로젝트입니다.

## 📌 프로젝트 개요
중고 상품을 쉽고 효율적으로 관리할 수 있는 웹 플랫폼입니다. 상품 게시글의 CRUD, 소셜 로그인 기능 및 사용자 인증 시스템 등을 갖추었으며, 최적화된 UI/UX로 사용성을 높였습니다.

## 🚀 주요 기능
- 상품 게시글 CRUD (등록, 수정, 삭제, 조회)
- OAuth2 기반 소셜 로그인 (카카오)
- 마이페이지를 통한 사용자 상품 관리
- 1:1 채팅기능
- TOSS 결제 기능
- 관리자 공지사항 기능

## 🛠️ 기술 스택
- **Back-end**: Java, Spring Boot, Spring Security, JPA, OAuth2, MySQL
- **Front-end**: Next.js, React, JavaScript, Tailwind CSS
- **CI/CD**: GitHub Actions, AWS(EC2,S3), Jenkins

## 🔑 나의 담당 역할 및 기여도
### 백엔드
- 상품 게시글 도메인의 CRUD 기능 구현
- OAuth2 기반 소셜 로그인 기능 개발 및 인증·인가 구축
- 글로벌 예외 처리 및 커스텀 JSON 응답 구현

### 프론트엔드
- 전체 UI 스토리보드 및 레이아웃 설계
- 마이페이지 핵심 기능 구현 및 UX 개선
- React Context API를 활용한 전역 로그인 상태 관리 구현
- Next.js middleware를 이용한 인증·인가 로직 구성
- SSR 환경에서 쿠키 최신 상태 동기화 해결

### 협업 관리 및 배포
- 커밋 규칙, PR 리뷰 방식, 브랜치 전략, 네이밍 컨벤션 등 개발 규칙 정립
- GitHub Actions를 통한 CI/CD 구축 및 자동화 테스트 환경 구성

## 🌟 프로젝트 성과
- 짧은 기간에도 실제 사용 가능한 안정적인 서비스를 성공적으로 배포
- 협업 효율성과 코드 품질 향상을 통해 팀 전체의 기술적 성장에 기여
